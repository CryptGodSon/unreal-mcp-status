Claude Code, Cursor, Copilot and other MCP clients control Unreal Engine through an MCP server running inside the editor. When that server is not reachable, or reachable but not working, the agent rarely says so clearly: tool calls time out, it gives up, or it tries a workaround. This extension puts one light in your status bar that tells you whether the connection works and, if it does not, why.

## Highlights

- **One glance.** Green, yellow or red in the status bar, checked every 3 seconds.
- **Checked like a real AI client.** When the server comes up, the extension connects the way your AI client does, reads the tool list and closes the session again. Green means tools are actually available, not just that a port is open.
- **Tells you why.** Editor closed, editor still starting, no tools, a different project open, or another program on the port: each has its own message and fix.
- **Right project.** Shows which project is open in Unreal and warns when it is not the one in your workspace.
- **Every engine version.** Epic's built-in Unreal MCP plugin in UE 5.8 works out of the box; community plugins for UE 5.5–5.7 and UE4 are one command away.
- **Quiet and light.** About 30 KB, no dependencies, no cloud, no telemetry. Checks pause while the window is in the background.
- **Windows, macOS and Linux.** English and Polish interface.

## What the light means

| Light | Meaning | What to do |
| --- | --- | --- |
| 🟢 **Unreal** | The MCP server works and offers tools. The tooltip shows the server, the number of tools and the open project. | Nothing. Go ahead. |
| 🟡 **Unreal** | Unreal Editor is running, but the MCP server does not answer. | Wait until the editor finishes loading. If it stays yellow, click the light, choose **Copy command** and paste it into the Unreal console. |
| 🟡 **Unreal** | Connected, but the server offers no tools. | Enable the toolset plugins in Unreal (for Epic's plugin, for example **EditorToolset**). |
| 🟡 **Unreal** | Unreal has a different project open than the one in this workspace. | Open the right project, or the AI will change the other one. |
| 🟡 **Unreal** | Something answers, but connecting like an AI client fails. | Check the plugin version and the Unreal Output Log. The tooltip shows the server's error. |
| 🟡 **Unreal** | Another program answers at the server's address. | Close that program, or change the port in Unreal and in the `unrealMcpStatus.url` setting. |
| 🔴 **Unreal** | Unreal Editor is not running. | Open your project. |

Hover over the light for details and quick actions: **Check now**, **Copy start command**, **Choose server** and **Settings**. Click the light to run the full check right away.

## Compatibility

| Unreal Engine | MCP plugin | Address | Setup |
| --- | --- | --- | --- |
| **5.8+** | Epic's **Unreal MCP** (built in, Experimental) | `http://127.0.0.1:8000/mcp` | None, this is the default. |
| **5.5–5.7** | [UnrealMCP](https://github.com/chongdashu/unreal-mcp) by chongdashu, and its forks | `tcp://127.0.0.1:55557` | **Unreal MCP: Choose MCP server** → pick it from the list. |
| **5.5** | [UnrealMCP](https://github.com/kvick-games/UnrealMCP) by kvick-games | `tcp://127.0.0.1:13377` | **Unreal MCP: Choose MCP server** → pick it from the list. |
| **Any, including UE4** | Any plugin that exposes MCP over HTTP or a TCP port | Your plugin's address | **Unreal MCP: Choose MCP server** → **Custom address…** |

The extension recognizes both the UE5 editor (`UnrealEditor`) and the UE4 editor (`UE4Editor`). For plugins that bridge to Unreal over a raw TCP socket, it checks that the plugin accepts connections; the tool list is read for HTTP servers only.

## Install

- **VS Code:** [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=montemr.unreal-mcp-status), or search for "Unreal MCP Status" in the Extensions view.
- **Antigravity, Cursor, VSCodium and other VS Code-based editors:** [Open VSX](https://open-vsx.org/extension/montemr/unreal-mcp-status).
- **From the command line:** `code --install-extension montemr.unreal-mcp-status`
- **Manually:** download the `.vsix` from [GitHub Releases](https://github.com/CryptGodSon/unreal-mcp-status/releases/latest) and run **Extensions: Install from VSIX…**

## Quick start with Epic's Unreal MCP plugin (UE 5.8)

1. **Enable the plugin.** In Unreal, open **Edit → Plugins**, search for **Unreal MCP** (Experimental), enable it and restart the editor.
2. **Check the server settings.** In **Edit → Editor Preferences → Plugins → Model Context Protocol**, keep the port at `8000` and the path at `/mcp`, and turn on **Auto Start Server**.
3. **Connect your AI client.** The plugin can write the client configuration for you. Run this in the Unreal console:
   ```
   ModelContextProtocol.GenerateClientConfig All
   ```
   Replace `All` with `ClaudeCode`, `Cursor`, `VSCode`, `Gemini` or `Codex` to set up just one client. For Claude Code you can also run:
   ```
   claude mcp add --transport http unreal http://127.0.0.1:8000/mcp
   ```
4. **Install this extension.** The light turns green as soon as the editor is ready.

## Older engine versions and other plugins

Run **Unreal MCP: Choose MCP server** from the Command Palette (or click **Choose server** in the tooltip) and pick your plugin. The extension sets the address and the start command for you. For a plugin that is not on the list, choose **Custom address…** and enter its address:

- `http://host:port/path` or `https://…` for MCP over HTTP,
- `tcp://host:port` for plugins with a TCP bridge.

## What the extension checks, and what it does not

**It checks:**

- that the MCP server answers (an MCP `ping` every few seconds, which needs no session);
- that it really works for an AI client: when the server comes up and when you click the light, it runs `initialize` and `tools/list`, counts the tools and ends the session with a `DELETE`, so nothing stays open in the editor;
- which project is open in Unreal, read from the editor's command line, compared with the `.uproject` in your workspace;
- whether Unreal Editor is running at all.

**It does not:**

- **run any tools.** Calling a tool to test it could change your project, so the extension only lists them;
- **check your AI client's permissions.** Whether Claude Code, Cursor or Copilot may use the tools is set in the client itself (for example `/permissions` in Claude Code);
- **read the tool list of TCP-bridge plugins.** They speak their own protocol, so only the connection is checked.

## Settings

| Setting | Default | Description |
| --- | --- | --- |
| `unrealMcpStatus.url` | `http://127.0.0.1:8000/mcp` | Address of the MCP server: `http://`, `https://` or `tcp://`. |
| `unrealMcpStatus.startCommand` | `ModelContextProtocol.StartServer` | Unreal console command that starts the server. Empty hides the **Copy command** button. |
| `unrealMcpStatus.intervalSeconds` | `3` | How often to check the connection, in seconds. |
| `unrealMcpStatus.verifyTools` | `true` | Connect like an AI client and read the tool list when the server comes up and on click. |
| `unrealMcpStatus.checkProject` | `true` | Show the open project and warn when it differs from the workspace. |
| `unrealMcpStatus.pauseWhenUnfocused` | `true` | Pause checking while the window is in the background. |
| `unrealMcpStatus.notifyOnChange` | `false` | Show a notification when the state changes, for example when the server comes up. |

## Commands

- **Unreal MCP: Check connection** runs the full check now and shows the result.
- **Unreal MCP: Choose MCP server** picks a plugin preset or a custom address.
- **Unreal MCP: Copy start server command** copies the start command for the Unreal console.
- **Unreal MCP: Open settings** opens this extension's settings.

## Troubleshooting

- **"Replying to Ping" fills the Unreal Output Log.** Epic's plugin logs every `ping`. Keep `unrealMcpStatus.pauseWhenUnfocused` on, raise `unrealMcpStatus.intervalSeconds`, or hide the messages by running `Log LogModelContextProtocol Warning` in the Unreal console.
- **"Connected, but no tools are available".** The server runs, but no toolset is registered. With Epic's plugin, enable the toolset plugins (for example **EditorToolset**) in **Edit → Plugins** and restart the editor.
- **"Unreal has a different project open".** Several projects or an older editor window may be open. Close the other editor or open the project from this workspace. You can turn the check off with `unrealMcpStatus.checkProject`.
- **"Port is used by another program".** Another app answers on the port. Close it, or pick a free port in the plugin settings and set the same address in `unrealMcpStatus.url` and in your AI client.
- **"MCP does not respond" stays yellow.** Check that the plugin's server is enabled (for Epic's plugin, **Auto Start Server**), or start it from the Unreal console with the start command.

## Privacy

The extension only talks to the address you configure (your own machine by default) and reads the local process list to find the editor and the project it has open. Nothing leaves your computer.

## Languages

English and Polish. The extension follows the display language of your editor.
